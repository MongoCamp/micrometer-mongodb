Getting Started ​

A library to monitor your MongoDB and push all your Micrometer Stats to an Mongodb.

Dependency Setup ​

Artifacts are published for Scala 3 (_3) and Scala 2.13 (_2.13). The Maven and Gradle examples use the Scala 3 artifact.

scala
libraryDependencies += "dev.mongocamp" %% "micrometer-mongodb" % "1.1.1.snapshot"
scala
def ivyDeps = Agg(
  ivy"dev.mongocamp:::micrometer-mongodb:1.1.1.snapshot"
)
xml
<dependency>
    <groupId>dev.mongocamp</groupId>
    <artifactId>micrometer-mongodb_3</artifactId>
    <version>1.1.1.snapshot</version>
</dependency>
groovy
dependencies {
    implementation "dev.mongocamp:micrometer-mongodb_3:1.1.1.snapshot"
}

Binder ​

Micrometer Core supports some build in Binder for MongoDb Monitoring. But when you want more statistics over other MongoDb Statistics you need individual bindings. Some Binders you can find in our binding collection.

Registry ​

Possibility to persist your Micrometer Stats to your MongoDB.
